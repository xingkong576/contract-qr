# CHARACTERS.md — 人物档案

## 主角

### 萧无锋（Xiao Wufeng）

| 属性 | 详情 |
|------|------|
| 年龄 | 出场16岁 |
| 身份 | 边陲小城"石山城"萧家旁系子弟 |
| 灵根 | "废灵根"——实则是九品混沌灵根，万年来唯一 |
| 性格 | 表面沉稳寡言，内心炽热；不圣母，不冷血，该狠就狠；重承诺，记仇但不记恨 |
| 武器 | 上古残玉（本命法宝），后期化为无名剑 |
| 修炼路线 | 混沌气路线——不走寻常路 |
| 金手指 | 上古残玉——内含远古大能"玄古"一缕残魂 + 混沌修炼之法 |
| 人物弧光 | 从"证明自己不是废柴" → "选择承担天道的重量" |
| 口头禅/标志 | 沉默时不解释，做事后让人自己去看 |

**人物小传：**
萧无锋母亲失踪，父亲早逝，在家族中地位低下。16岁那年家族灵田测试，众人发现他的灵根"驳杂不堪"，被评为废柴。当夜，他独自在后山冥想时，一块从母亲遗留物中从未启用的残玉忽然发烫，一缕远古大能玄古的残魂入体，传授混沌修炼之法。从此，别人眼中的"弯路"，成了他的"独路"。

## 核心配角

### 苏清雪（女主）

| 属性 | 详情 |
|------|------|
| 年龄 | 出场17岁 |
| 身份 | 青云宗圣女 |
| 灵根 | 天品冰灵根 |
| 性格 | 外冷内热，骨子里倔强不服输；对修炼极其专注，对感情迟钝 |
| 武器 | 霜华剑 |
| 与主角关系 | 初遇时看不起他 → 了解后欣赏 → 并肩作战 → 心意相通 |
| 人物弧光 | 从"宗门规则高于一切" → "有自己的选择和判断" |

**人物小传：**
青云宗最年轻的圣女，冰灵根觉醒后修炼速度惊人，被誉为百年难遇的天才。但她内心背负着宗门的期望和压力——她不是想当圣女，是被选中的。遇到萧无锋后，她第一次看到了"不被命运选择"的人。

### 赵天霸（兄弟）

| 属性 | 详情 |
|------|------|
| 年龄 | 出场16岁，与萧无锋同龄 |
| 身份 | 石山城赵家嫡子，体修天才 |
| 性格 | 豪爽直接，讲义气，脑子不如嘴快但关键时刻脑子也灵 |
| 武器 | 巨锤——玄铁重锤 |
| 与主角关系 | 从小一起长大的死党，第一个发现萧无锋"不简单"的人 |
| 人物弧光 | 从"跟着萧无锋混" → "走自己的体修大道" |

**人物小传：**
赵家家主之子，天生神力，走的是体修路线。在灵石为王的修仙界，体修被认为是"下等修行"。萧无锋是唯一不把他当怪人看的人。两人从小一起长大，打了一起长大，挨了一起挨。

### 白老 / 玄古（导师）

| 属性 | 详情 |
|------|------|
| 年龄 | 实际寿命不知，残魂形态 |
| 身份 | 远古大能玄古的一缕残魂，寄宿于上古残玉 |
| 性格 | 表面看似慵懒随性，实则洞察世事；说话带刺但心不坏；偶尔会爆出一两句古语 |
| 与主角关系 | 师徒——混沌功法传授者，人生引路人 |
| 命运 | 第三卷中后期为保护萧无锋残魂消散 |

**人物小传：**
玄古曾是苍玄界最强的修士之一，万年前天道崩裂时他为护住残玉中的混沌之法而兵解。一缕残魂进入残玉沉睡，等待"混沌灵根"的继承者。他把萧无锋当徒弟养，把萧无锋当儿子疼，最后为了保护徒弟献出了残魂。

### 林风（对手→盟友）

| 属性 | 详情 |
|------|------|
| 年龄 | 出场17岁 |
| 身份 | 中州林氏子弟，剑道天才 |
| 性格 | 骄傲但心胸宽广，尊重强者；认定的事九头牛拉不回 |
| 武器 | 青萍剑 |
| 与主角关系 | 初期竞争对手 → 中期亦敌亦友 → 后期生死之交 |
| 人物弧光 | 从"剑道唯我独尊" → "剑为心，不为胜" |

**人物小传：**
林氏百年最天才的剑修，天生剑骨，一出生就被认定为剑道奇才。第一次见到萧无锋时，他完全看不懂对方的修炼方式——不灵气，不凝元，像在"瞎练"。后来被萧无锋击败，心服口服，从此成为亦敌亦友的关系。

### 夜无涯（反派）

| 属性 | 详情 |
|------|------|
| 年龄 | 出场时约200岁（修炼者外表约30岁） |
| 身份 | 魔宗——幽冥宗宗主，号称"魔尊" |
| 性格 | 亦正亦邪，行事随心所欲但有底线；认为正道虚伪，但并非纯粹恶人 |
| 武器 | 幽冥尺 |
| 与主角关系 | 亦敌亦友，多次交锋，偶尔合作 |
| 人物弧光 | 从"对抗天道秩序" → "理解选择的重量" |

**人物小传：**
夜无涯曾是正道天才是，但因亲眼目睹正道高层为争夺天道碎片而互相残杀，心灰意冷后叛出正道，创立幽冥宗。他反对的不是正道，而是虚伪的正道。他与萧无锋的理念有碰撞也有共鸣——两人都选择了不被认可的道。

### 萧战（长辈）

| 属性 | 详情 |
|------|------|
| 年龄 | 约50岁 |
| 身份 | 石山城萧家家主，萧无锋的祖父 |
| 性格 | 严厉护短，外冷内热；家族利益至上但对血脉亲人极度保护 |
| 武器 | 萧家长枪 |
| 与主角关系 | 祖父——对萧无锋期望不高但不容外人欺负 |

**人物小传：**
萧家现任家主，元丹境修士。对萧无锋这个孙子态度复杂——既觉得他丢人又忍不住护着。家族遇到危机时第一个站出来说"我萧家的子弟，轮不到外人说"。

## 人物关系核心冲突

| 关系 | 冲突点 | 和解/发展 |
|------|--------|-----------|
| 萧无锋 vs 家族 | "废柴"身份带来的歧视 | 萧无锋证明自己后，家族态度转变 |
| 萧无锋 vs 苏清雪 | 身份差距、修炼理念不同 | 互相理解，成为彼此最信任的人 |
| 萧无锋 vs 赵天霸 | 几乎无冲突，最多拌嘴 | 死党中的死党 |
| 萧无锋 vs 林风 | 天才之间的竞争 | 互相认可，成为生死之交 |
| 萧无锋 vs 夜无涯 | 理念冲突——秩序 vs 自由 | 多次交锋后产生微妙共鸣 |
| 萧无锋 vs 白老 | 师徒传承中的严格与叛逆 | 最终成为亦师亦父的关系 |
