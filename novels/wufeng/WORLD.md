## 苍玄界总览

### 地理格局

苍玄界分为**九州**：

```
          天穹
    ┌───────────┐
    │           │
北原 │    中州    │ 西漠
    │           │
    └───────────┘
    │           │
    │           │
东荒 │   南岭    │ 东海
    └───────────┘
```

| 地域 | 特点 | 修炼风气 | 代表势力 |
|------|------|----------|----------|
| **中州** | 大陆中心，灵气最浓郁，上古遗迹最多 | 正统修仙，宗门林立 | 青云宗、天剑宗、丹塔 |
| **东荒** | 边陲之地，灵气稀薄，民风彪悍 | 家族式修炼为主 | 石山城（萧家、赵家） |
| **西漠** | 沙漠戈壁，资源匮乏 | 苦修为主，强者极多 | 沙门、佛修 |
| **南岭** | 十万大山，妖兽横行 | 御兽、巫修盛行 | 万兽谷、巫神殿 |
| **北原** | 冰原雪域，环境恶劣 | 体修、冰灵修者聚集 | 冰原部落 |
| **东海** | 群岛海域，灵岛众多 | 航海、阵法、炼丹 | 碧海门、龙族后裔 |
| **西天** | 高原圣地，佛修发源地 | 佛修、魂修 | 西天佛国 |
| **北冥** | 迷雾深海，未知之地 | 魔修聚集 | 幽冥宗（总部） |
| **天穹** | 大陆最神秘，上古天梯所在 | 传说通往上界 | ？？？ |

## 修炼体系详解

### 凡尘九境

每一境分：初期 → 中期 → 后期 → 巅峰

#### 1. 引气境（凝）
- **描述：** 感应天地灵气，打开身体灵脉
- **标志：** 灵纹显化（皮肤下可见灵气纹路）
- **寿命：** 120年
- **战力：** 可一拳打碎巨石，轻身术（小范围跳跃）

#### 2. 凝气境（气）
- **描述：** 灵气化元，在经脉中形成"气海"
- **标志：** 气海可见（丹田处泛光）
- **寿命：** 150年
- **战力：** 可御气伤人（灵力外放3米），身轻如燕

#### 3. 元丹境（丹）
- **描述：** 气海凝丹，灵力质变
- **标志：** 丹田结丹
- **寿命：** 300年
- **战力：** 灵力化为实质武器（灵刃），飞行能力（低空滑翔）

#### 4. 元神境（神）
- **描述：** 凝练元神，感知天地变化
- **标志：** 元神初生（头顶隐约可见光影）
- **寿命：** 500年
- **战力：** 神识外放（感知半径1里），可御物飞行

#### 5. 元海境（海）
- **描述：** 灵力如海，取之不尽
- **标志：** 灵力化为金色（金元）
- **寿命：** 800年
- **战力：** 一掌可摧毁山丘，神识覆盖方圆百里

#### 6. 元婴境（婴）
- **描述：** 元神化婴，肉身可毁元神不灭
- **标志：** 元婴出窍
- **寿命：** 1500年（元婴不灭可转世重修）
- **战力：** 可呼风唤雨，一击摧毁城池

#### 7. 化境（化）
- **描述：** 领悟天地法则，灵力转化为"法力"
- **标志：** 法力具现（身边形成法则领域）
- **寿命：** 3000年
- **战力：** 一击可改变地形

#### 8. 劫境（劫）
- **描述：** 面对天劫，渡劫成功则超脱
- **标志：** 天劫降临（九九天劫）
- **寿命：** 5000年（渡劫后与天同寿）
- **战力：** 毁天灭地

#### 9. 乘境（乘）
- **描述：** 大乘之境，传说中的境界
- **标志：** 与天道合一
- **寿命：** 与天地同寿
- **战力：** 不可知

### 特殊路线：混沌九转

| 转数 | 相当于凡尘境界 | 特点 |
|------|---------------|------|
| 混沌一转 | 凝气境 | 混沌气入门，可吞噬其他灵气 |
| 混沌二转 | 元丹境 | 灵力化混沌色 |
| 混沌三转 | 元神境 | 元神带混沌属性 |
| 混沌四转 | 元海境 | 混沌气海 |
| 混沌五转 | 元婴境 | 混沌元婴 |
| 混沌六转 | 化境 | 混沌领域 |
| 混沌七转 | 劫境 | 混沌天劫（不同于普通天劫） |
| 混沌八转 | 大乘 | 混沌大成 |
| 混沌九转 | ？？？ | 传说之境 |

### 混沌气特性

- **吞噬：** 可吞噬其他灵气转化为混沌气（但速度极慢）
- **化用：** 可模拟、化用其他灵气属性的攻击
- **纯净：** 灵力最纯净，不受属性克制
- **代价：** 修炼速度极慢，普通人无法承受
