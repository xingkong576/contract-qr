# OUTLINE.md — 全书分卷大纲

## 第一卷：小城风云（第1-200章）

### 卷核心

**一句话：** 废柴觉醒，逆天之路起步。

**主线：** 萧无锋在石山城萧家的废柴生活 → 残玉觉醒 → 修炼初成 → 家族大比一战成名 → 离开石山城，踏入修仙界。

**副线：** 母亲失踪线索初现（遗物中的残玉）

**情绪基调：** 压抑 → 希望 → 成长 → 离别

### 分章大纲

---

#### 第一部分：废柴之子（第1-20章）

**第1章 石山城**
- 开篇：石山城全景，萧家灵田日
- 萧无锋在家族中处境——旁系子弟，灵根测试"废柴"
- 日常：被其他旁系子弟嘲讽，但从不争辩
- 暗示：母亲遗留的一块残缺玉佩，从未启用的古怪
- **伏笔F3：** 母亲失踪前曾说"那块玉终有一天会发光"
- 钩子：夜，萧无锋独自在后山冥想，玉佩忽然发烫

**第2章 残玉**
- 深夜后山，残玉发烫，一股力量涌入萧无锋体内
- 玄古残魂初现——看似慵懒的老者
- 玄古试探萧无锋，确认其灵根为"九品混沌灵根"
- 玄古讲述万年前天道崩裂的故事（部分）
- 传授混沌修炼第一式——"纳气归混沌"
- 钩子：萧无锋开始修炼，但发现此法极难

**第3章 第一步**
- 玄古解释为何叫"废灵根"——不是废，是太难修炼
- 玄古设定第一个修炼目标：三天内感应到混沌气
- 萧无锋闭关三天三夜，玄古监督但不插手
- 第三天深夜，终于感应到一丝混沌气
- 玄古露出微笑："总算没看错人"
- 钩子：第四天清晨，萧无锋修为微变——引气境初期

**第4章 家族日**
- 萧家每月一次的"家族日"——旁系子弟汇报修为进展
- 萧无锋汇报"仍在引气境初期"，引来嘲笑
- 萧战（祖父）冷冷看了他一眼，没说什么
- 赵天霸为萧无锋打抱不平，和嘲笑他的人打了一架
- 赵天霸发现萧无锋身上气息有变化，但说不出所以然
- 钩子：玄古说"该练练手了"

**第5章 夜练**
- 玄古指导萧无锋修炼混沌气的基本功——"吞、化、融"
- 萧无锋在夜间偷偷修炼，白天照常当"废柴"
- 玄古说修炼混沌气需要一个"容器"——需吸纳少量其他灵气
- 萧无锋在灵田吸收驳杂灵气，意外进展顺利
- 赵天霸偷偷跟踪萧无锋，看到诡异一幕
- 钩子：赵天霸撞见萧无锋修炼，但萧无锋骗过了他

**第6章 秘密**
- 赵天霸逼问萧无锋秘密，萧无锋拒绝透露
- 两人约定"你若遇到危险我帮，但别问我修炼什么"
- 赵天霸同意，转而讲述自己修炼体遇到的瓶颈
- 萧无锋用玄古的知识帮赵天霸分析了问题所在
- 赵天霸震惊——废柴怎么懂这么多？
- 钩子：家族大比通知发布——一个月后

**第7章 家族大比**
- 萧家族大比规则：旁系子弟均可参加
- 前三名可获得进入家族藏书阁的资格
- 萧无锋决定参加——既是测试修炼成果，也是机会
- 玄古表示"就当去玩玩"，但认真指导他
- 准备期间：萧无锋的修为提升至引气境初期巅峰
- 钩子：大比第一天，第一个对手就是之前嘲笑过他的谢虎

**第8-10章 大比初赛**
- 谢虎（旁系天才，引气境中期）vs 萧无锋
- 谢虎轻敌，被萧无锋一招击败——但用了七成实力掩饰
- 第二轮、第三轮接连取胜，对手越来越强
- 旁系子弟开始觉得"废柴"不对劲
- 萧战在观战台眯起眼睛
- 钩子：半决赛对手——赵天霸

**第11-13章 兄弟对决**
- 半决赛：赵天霸 vs 萧无锋
- 赵天霸知道萧无锋有秘密，但大比上不会放水
- 体修vs混沌修的第一次碰撞
- 萧无锋以巧妙的战术击败赵天霸
- 赵天霸心服口服，但不服输
- 赵天霸在决赛中败给另一旁系，两人约好"下次一定赢你"
- 钩子：决赛开始——萧无锋 vs 谢龙（萧家长子旁支）

**第14-17章 决赛**
- 谢龙：引气境后期，萧家长子，一直看不起萧无锋
- 决赛开始，谢龙毫不留情，直接全力出手
- 萧无锋被迫动用更多实力
- 关键时刻，萧无锋首次使用"混沌化用"——模仿谢龙的攻击方式反制
- 击败谢龙，获得大比第一名
- 全场哗然——废柴逆袭
- 钩子：萧战宣布——萧无锋可进入藏书阁深处

**第18-20章 藏书阁**
- 藏书阁深处存放萧家最高深的功法
- 萧无锋在其中发现一本远古炼体术——与混沌修炼相辅相成
- 玄古认出此功法——远古流传的辅助功法
- 萧无锋修为在藏书阁中突破至引气境巅峰
- 萧战私下约谈萧无锋，话中有话："你最近变了"
- 钩子：萧战透露——当年萧无锋母亲失踪前，也来过这里，但找的不是功法

#### 第二部分：风云初起（第21-50章）

**第21-25章 母亲的遗物**
- 萧无锋开始调查母亲失踪一事
- 玄古提醒他"不要急，有些事情现在知道太早"
- 萧无锋在藏书阁发现一本关于"灵石矿脉"的记载
- 萧家东面的黑风山发现新矿脉，需派人勘探
- 萧无锋主动申请加入勘探队
- 钩子：勘探队出发——第一站：黑风山深处

**第26-30章 黑风山**
- 勘探队在黑风山发现异常——灵气波动远超正常矿脉
- 山中发现上古遗迹入口
- 领队修士不敢深入，萧无锋决定自己去
- 遗迹中第一个试炼——通过混沌灵气感应
- 遗迹墙上刻有远古文字——玄古解读出关键信息
- 钩子：遗迹深处有一具白骨，手中握着一枚戒指

**第31-35章 戒指与线索**
- 戒指中残存一缕信息——母亲来过这里
- 信息碎片显示：母亲被人"引"走的，不是失踪
- 引她的人是——一个使用幽冥功法的人
- 玄古神色凝重："幽冥功……万年前就有这个功法了"
- 萧无锋决定要变强，找出真相
- 钩子：离开黑风山时，有人在暗中监视萧无锋

**第36-40章 暗中窥视**
- 萧无锋察觉被跟踪，利用地形甩掉跟踪者
- 但发现对方实力不弱——元丹境
- 萧家的元丹境强者中，没有用过幽冥功法的人
- 玄古推断：萧家内部有叛徒或外敌渗透
- 萧无锋暂不声张，暗中调查
- 钩子：家族中一个平时不起眼的旁系突然失踪

**第41-45章 内鬼**
- 失踪的旁系子弟叫谢明，是负责黑风山勘探记录的
- 萧无锋潜入谢明住处，发现密信——与幽冥宗有关
- 萧家有人向幽冥宗出卖情报
- 萧无锋将情报交给萧战，萧战震怒
- 萧战清洗内鬼，但发现渗透不止一个
- 钩子：萧战决定送萧无锋外出——去中州的青云宗

**第46-50章 离别**
- 萧战告诉萧无锋：青云宗即将开启招收弟子
- 萧无锋是离开石山城最好的时机
- 萧战亲自送萧无锋到城门，只说了一句："别给萧家丢脸"
- 赵天霸在城外十里亭送行
- 玄古说"终于要去看更大的世界了"
- **卷末：** 萧无锋踏上前往中州的道路，背后是石山城渐远的灯火

#### 第三部分：踏入修仙界（第51-100章）

**第51-55章 旅途**
- 前往中州的旅程——第一次见识修仙界的全貌
- 路遇妖兽袭击，萧无锋首次实战
- 路遇修仙者拍卖会，萧无锋用家中积蓄买了几块低阶灵石
- 偶遇一个江湖骗子修士，被坑了一笔
- 玄古在一旁幸灾乐祸："修仙界的第一课——别太老实"
- 钩子：到达中州边界——青云宗山门外

**第56-62章 入门试炼**
- 青云宗入门试炼：测灵根、试炼塔、实战考核
- 萧无锋的"废灵根"在青云宗也被视为下下之选
- 试炼塔：萧无锋利用混沌灵气，越层效率惊人
- 试炼塔最高层——第一百层，百年无人到达
- 萧无锋到达第一百零一层（隐藏层）
- 守卫震惊，但灵根限制——只能收为"外门弟子"
- 钩子：外门大比，外门弟子中争夺内门资格

**第63-70章 外门生活**
- 外门弟子聚居地——条件艰苦，竞争激烈
- 萧无锋结识了几个外门好友：胖哥（搞笑担当）、小月（炼丹学徒）
- 白天正常上课修炼，夜晚偷偷修炼混沌气
- 玄古指导他适应青云宗的灵气环境
- 外门师兄——王浩，一个自命不凡的内门预备役
- 钩子：外门大比开始

**第71-80章 外门大比**
- 外门大比规则：81人参与，前9名进入内门
- 萧无锋一路过关斩将，但刻意隐藏实力
- 四分之一决赛对阵王浩
- 王浩认出萧无锋——就是试炼塔那个"怪胎"
- 对决——萧无锋用外门标准实力击败王浩
- 钩子：半决赛，对手让萧无锋想到了一个人

**第81-88章 重逢苏清雪**
- 半决赛对手——苏清雪！
- 苏清雪已经是内门弟子，奉命监督外门大比
- 但苏清雪亲自下场——外门弟子不得要求内门代替
- 冰灵根vs混沌气的初次碰撞
- 苏清雪感受到了萧无锋的不凡，但没有点破
- 萧无锋险胜——用了九成功力
- 钩子：决赛对手出现——外门第一人，柳乘风

**第89-95章 决赛**
- 柳乘风：外门公认第一，元丹境初期
- 决赛激烈，萧无锋被迫动用混沌气的吞噬特性
- 击败柳乘风，获得外门大比第一名
- 苏清雪在台下看着，若有所思
- 青云宗长老们开始关注这个"废灵根"的少年
- 钩子：宗主亲自召见

**第96-100章 宗主召见**
- 青云宗宗主——青云真人，化境修为
- 宗主问萧无锋修炼功法来源——萧无锋说是自己摸索
- 宗主不信，但没说破
- 破格提拔：萧无锋进入内门，且可进入"藏经阁"
- 苏清雪被指派为萧无锋的内门"引路人"
- 萧无锋初入内门，新的开始
- **第一阶段小结：** 废柴入青云，隐龙之姿初露

#### 第四部分：宗门风云·起（第101-150章）

**第101-110章 内门生活**
- 内门环境完全不同——资源丰厚，竞争更激烈
- 萧无锋分配到的修炼洞府——偏远但灵气浓郁
- 苏清雪作为"引路人"第一次正式与萧无锋对话
- 两人性格不同，但互相尊重
- 苏清雪教萧无锋青云宗的正统修炼法——萧无锋暗中对比
- 钩子：宗门任务发布——探索"迷雾谷"

**第111-120章 迷雾谷**
- 青云宗组织外门精锐弟子探索迷雾谷
- 迷雾谷中有上古阵法残留，灵气混乱
- 队伍中有人认识萧无锋——外门大比的第一名
- 谷中发现一个小型上古遗迹
- 遗迹中有炼丹室——萧无锋第一次接触炼丹
- 钩子：遗迹深处有异动——不是遗迹本身的东西

**第121-130章 谷中异变**
- 迷雾谷中出现了不明修士——幽冥宗的人！
- 他们在寻找什么东西——和碎片有关的线索
- 萧无锋的队伍被分成几组，萧无锋和苏清雪一组
- 两人在谷中遭遇幽冥宗弟子
- 混战中，萧无锋被迫全力出手——苏清雪看到了他的真正实力
- 钩子：战斗结束后，苏清雪问："你到底是谁？"

**第131-140章 秘密与信任**
- 萧无锋没有告诉苏清锋全部秘密，但部分坦白
- 苏清雪选择相信——因为她看到了萧无锋的战斗方式不是邪功
- 两人关系发生微妙变化
- 迷雾谷事件上报宗门，宗主震怒——幽冥宗渗透太深
- 青云宗开始内部整顿
- 钩子：宗门大比提前——宗门内最强的较量

**第141-150章 宗门大比**
- 青云宗三年一度的宗门大比
- 内门所有弟子参与，前3名可获得宗主亲自指点
- 萧无锋作为新晋内门弟子参赛
- 第一轮、第二轮轻松过关
- 四分之一决赛对阵林风——第一次见到未来的"生死之交"
- 钩子：林风在战斗中感受到萧无锋的与众不同

#### 第五部分：宗门风云·变（第151-200章）

**第151-160章 大比后续**
- 萧无锋进入八强，但被林风击败
- 林风 impressed，主动结交
- 两人约定"下次一定分高下"
- 玄古提醒萧无锋："林风此人，日后必成大器"
- 萧无锋继续修炼，混沌二转进展顺利
- 钩子：青云宗传来急报——宗门被围

**第161-170章 宗门危机**
- 幽冥宗联合其他魔修势力攻打青云宗
- 青云宗宗主率众抵抗，但对方实力远超预期
- 萧无锋第一次参加宗门大战
- 战斗中，萧无锋救了苏清雪一命
- 萧战突然出现在战场上——原来他早已暗中关注青云宗局势
- 钩子：幽冥宗宗主现身——夜无涯！

**第171-180章 夜无涯**
- 夜无涯亲自出手，化境修为碾压青云宗护宗大阵
- 但夜无涯的目标不是青云宗——他在寻找某样东西
- 萧无锋感应到——残玉在回应某种力量
- 夜无涯似乎也感应到了残玉——他的目光在萧无锋身上停留了一瞬
- 玄古脸色大变："他感应到了！"
- 钩子：宗主决定献祭护宗大阵，萧无锋被指派带着重要功法逃跑

**第181-190章 覆灭之夜**
- 护宗大阵被破，青云宗沦陷
- 大量弟子伤亡，宗主在献祭中陨落
- 萧无锋在赵天霸和萧战的掩护下逃脱
- 苏清雪被困——萧无锋要不要回去救她？
- 玄古说："有些选择，决定了你将成为什么样的人"
- 萧无锋折返，救出了苏清雪
- 钩子：两人逃出青云宗，身后是燃烧的山门

**第191-197章 逃亡与重建**
- 萧无锋、苏清雪、赵天霸三人踏上逃亡之路
- 萧战选择留下——"我萧家的老祖宗，不能当逃兵"
- 萧战在逃亡后自爆，与三名元婴境魔修同归于尽
- 萧无锋悲痛，但也坚定了变强的决心
- 三人暂时隐居在一个偏僻小镇
- 萧无锋突破混沌三转
- 钩子：玄古说"是时候寻找其他幸存者了"

**第198-200章 第一卷终**
- 萧无锋找到几名青云宗幸存者——包括几个外门师弟
- 他们决定重建青云宗
- 但第一要务——变强
- 萧无锋立誓："总有一天，我要让幽冥宗付出代价"
- 第一卷结束，第二卷开始：重建宗门，纵横捭阖
- **第一卷核心主题完成：** 小城废柴 → 青云弟子 → 宗门覆灭 → 重建之志

## 第二卷：宗门风云（第201-500章）

### 卷核心

**一句话：** 废墟之上重建宗门，天才少年纵横捭阖。

**主线：** 重建青云宗 → 招募弟子 → 宗门大比崛起 → 残玉第二层解锁 → 与正道宗门合作对抗魔修

**副线：** 苏清雪的心理重建；赵天霸体修突破；林风的成长线

**关键事件：**
- 重建青云宗
- 百宗大会，一鸣惊人
- 残玉第二层解锁——获得远古传承片段
- 与林风达成合作
- 正魔暂时和平谈判

### 结构概要
