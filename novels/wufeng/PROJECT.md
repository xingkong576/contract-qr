## 高概念简介

> 一个被修仙界视为"废柴"的少年，因为一块来历不明的残玉，踏上一条无人能懂的逆天修行之路。
>
> 所有人都以为他在走弯路，其实他走的是万年来无人走过的道。

## 核心设定

### 世界观：苍玄界

- 天地灵气分九品，修炼者从引气到渡劫，共分九重天
- 万年前"灵潮枯竭"，天道崩裂，九块天道碎片散落四方
- 修炼之路变得九曲十八弯，正统功法效率极低
- 九州大陆：东荒、西漠、南岭、北原、中州、东海、西天、北冥、天穹

### 修炼体系

```
凡尘九境：
  1. 引气入体（凝）
  2. 凝气成元（气）
  3. 元丹初成（丹）
  4. 元神初生（神）
  5. 元海无量（海）
  6. 元婴破虚（婴）
  7. 化神归一（化）
  8. 渡劫飞升（劫）
  9. 大乘（乘）

每一境分：初期 → 中期 → 后期 → 巅峰

特殊路线（主角独有）：
  混沌一至九转（每转约等于一个大境界）
  混沌气——万法根源，可吞噬、化用其他灵气
```

## 写作要点

1. 战斗场面——每个境界的战力差距要写出来，避免战力崩坏
2. 升级节奏——每30-50章一个小突破，每200章一个大境界
3. 感情线——细水长流，不要过早在一起
4. 配角塑造——每个重要配角有自己的故事线
5. 地图扩展——从小城→宗门→九州→上界，循序渐进
6. 轻松与沉重交替——连续紧张章节后插入日常章节调剂
7. 伏笔意识——每章至少埋一个未来回收的伏笔
8. 章节钩子——每章结尾留悬念
