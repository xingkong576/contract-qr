## 网格回测修正

### 问题
之前的 `backtest_601778.py` 中 `grid_profit = total_sold - total_bought` 是错误的：
- `total_bought` 包含了所有买入金额（包括未卖出的持仓）
- `total_sold` 只包含已卖出金额
- 两者相减为负不代表亏损，而是因为大量持仓未平仓

### 修正
改为 **已实现利润 = sum(每笔卖出的盈利)**：
```
profit = (sell_qty * sell_price * (1 - 0.0005)) - (buy_qty * buy_price)
```
每笔卖出时立即计算盈利并累加。
