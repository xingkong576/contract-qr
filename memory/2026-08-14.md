## 选股脚本详细识别（21:03）
用户回忆"用几个条件海选优质票"的脚本，找到两个：

### astock-screener.py（A股选股v5）
- 数据源：腾讯财经（qt.gtimg.cn）
- 技术面：均线系统、MACD、RSI、布林带、成交量形态、KDJ
- 评分逻辑：均线(0-6)+MACD(0-5)+成交量(0-3)+RSI(0-3)+KDJ(0-2)+布林带(0-3)，总分0-20
- 评级：A++(>=8) → A+(>=6) → B(>=4) → C(>=2) → D(>=0) → F(<0)
- 8组共振筛选：
  1. MACD金叉+KDJ金叉+放量
  2. 多头排列+MACD金叉
  3. 多头排列+MACD金叉+放量
  4. 站上MA60+多头排列+MACD金叉+放量
  5. 高分(>=8)+站上全部4均线
  6. 高分(>=7)+站上MA60+MACD金叉
  7. 最强共振：多头+MACD金叉+KDJ金叉+放量+高分>=8
  8. 双金叉+站上MA60+高分(>=7)

### trend-screener.py（趋势选股v1）
- 数据源：腾讯财经
- 趋势分析：均线角度、ADX趋势强度、量价配合、形态趋势
- 评分维度：均线角度(0-5)+均线发散(0-4)+价格趋势(0-4)+ADX(0-3)+量价配合(0-3)+突破形态(0-5)+涨幅健康(0-3)+均线收敛(0-1)，总分0-30
- 评级：A++(>=15) → A+(>=12) → A(>=10) → B+(>=8) → B(>=6) → C(>=4) → D(<4)
- 6组共振筛选：
  1. 高分(>=12)+趋势强化+量价配合
  2. 高分(>=12)+ADX>40+突破60日高
  3. 高分(>=12)+趋势强化+趋势放量
  4. 最强：>=14+趋势强化+ADX>40+突破60日高+量价配合
  5. 均线发散+高分(>=10)+ADX>30
  6. 趋势良好(>=10)+回踩支撑+趋势强化
