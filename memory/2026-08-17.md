### 任务
将合同详情信息（合同编号 YS202210411）生成微信可扫描的二维码。

### 最终方案
- **脚本**：`gen-qr.js`（workspace 根目录）
- **原理**：本地 HTTP 服务（动态端口）→ localhost.run SSH 隧道（公网 URL）→ qrcode 生成 PNG
- **输出**：默认桌面 `contract_qr.png`

### 用法
```bash
node gen-qr.js                              # 默认：桌面输出，自动隧道
node gen-qr.js my_qr.png 600                # 指定路径和尺寸
node gen-qr.js --no-tunnel                  # 只生成本地 URL（手机需同 WiFi）
```

### 关键依赖
- Node.js >= 16
- `qrcode` 包（已安装）

### 经验教训
1. **原始二维码是手绘假码** — 微信无法扫描的根本原因
2. **PowerShell + exec 的 stderr 问题** — 改为 spawn 避免参数解析问题
3. **隧道有时效性** — localhost.run 临时隧道，关机/断网后失效
4. **端口可能被占用** — 已改用动态端口（listen 0）
5. **二维码需高纠错级别** — errorCorrectionLevel='H' 确保可扫描

### 遗留问题
- 临时隧道 URL 有时效，需重新运行脚本生成新二维码
- 如需永久链接，建议部署到 GitHub Pages / Cloudflare Pages
