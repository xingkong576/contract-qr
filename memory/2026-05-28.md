## 豆包 (Doubao) 自动化操作流程建立

今天完成了豆包网页的自动化操作流程，具体过程：

1. **打开浏览器**: 用 agent-browser 内置 Chromium 打开 `https://www.doubao.com/chat/`
   - 最初尝试用 Edge，但 agent-browser 不支持指定浏览器路径，Chromium 与 Edge 同内核，效果一致
   - 第一次尝试时页面需手动登录，用 `--headed` 模式让用户手动登录

2. **登录与状态保存**:
   - 用户手动登录后，用 `agent-browser state save doubao_auth.json` 保存登录态
   - 登录态文件保存于 workspace 根目录 `doubao_auth.json`

3. **发送写作指令**:
   - 主题：AI时代人类最不可替代的是什么？（从创造力、情感共鸣、生命体验三个角度）
   - 用 `agent-browser type textarea "指令内容"` 输入
   - 用 `agent-browser press Enter` 提交
   - 注意：`agent-browser fill @ref` 和 `find text / find role` 对 textarea 偶有不生效，`type textarea` 选择器最可靠

4. **获取生成结果**:
   - 豆包的文档内容渲染在飞书文档 iframe 中
   - 通过 `document.querySelectorAll('iframe')[0].contentDocument.body.innerText` 提取完整内容
   - 生成的标题：《智潮奔涌，人心为锚》

5. **安装反防爬技能**:
   - 安装了 `web-anti-crawl-search`（@dlutwuwei）— 用无头浏览器多引擎搜索，绕过反爬
   - 安装了 `web-anti-crawl-fetch`（@dlutwuwei）— 用 Playwright + Stealth 插件抓取网页转 Markdown，绕过浏览器指纹检测
   - 位置：`skills/web-anti-crawl-search/` 和 `skills/web-anti-crawl-fetch/`
   - 依赖已安装（playwright-extra, puppeteer-extra-plugin-stealth, turndown）

6. **头条号发布文章**:
   - 登录：`https://mp.toutiao.com/` — Chromium headed 模式，用户手动登录
   - 登录态保存：`toutiao_auth.json`
   - 发布页面：`https://mp.toutiao.com/profile_v4/graphic/publish`
   - 标题输入：`textarea[placeholder*="标题"]` 用 `type` 命令填入
   - 正文输入：`document.querySelector('.ProseMirror').innerText = '...'` 设置内容
   - 发布按钮：点击「预览并发布」按钮
   - 注意：可能触发验证码（verify.zijieapi.com），需人工验证
   - 发布成功后页面会清空重置

7. **关键经验**:
   - 未登录状态下可以点击建议问题，但AI不会回复（弹出"登录以解锁更多功能"）
   - 登录后一切正常
   - 使用 `--headed` 模式让用户完成首次登录，之后用 state save/load 复用
   - 刷新页面后需重新 load state
   - agent-browser 的 find text click 对 @ref 元素偶有失败，用 JS eval 点击更可靠
   - checkbox 通过 JS 操作 label.click() 而不是直接操作隐藏的 input
   - 发布后 API 调用 POST /mp/agw/article/publish 返回 200 即为成功
   - ⚠️ 关键教训：必须选择封面样式（单图/三图/无封面），否则自动点击「预览并发布」不会触发真正的发布
     - 下次需用 `document.querySelector('input[type=radio][value=1]').click()`（1=无封面）

## 小红书 (Xiaohongshu) 发布流程打通

今天成功实现了豆包写稿 + 小红书全自动发布的完整流程，以下是关键记录：

### 流程步骤
1. **豆包写稿**：打开豆包 → load 登录态 → `type textarea` 输入小红书风格写作指令 → `press Enter` 发送 → 等待响应 → 从飞书 iframe 提取内容
2. **打开小红书创作者平台**：`agent-browser open` + `state load xiaohongshu_auth.json`
3. **进入写长文编辑器**：`?from=menu&target=article` → 点击「新的创作」
4. **填入标题与正文**：标题用 `type textarea[placeholder*="标题"]`，正文用 `.ProseMirror.innerHTML = '<p>...</p>'`
5. **一键排版**：通过 JS 找到 `<button>一键排版</button>` 并 click()
6. **下一步**：等待排版完成，找到 `<button>下一步</button>` 并 click()
7. **发布笔记**：`document.querySelector('xhs-publish-btn')._onPublish()`

### 关键发现
- ❗ **发布按钮是 Vue 自定义组件** `<xhs-publish-btn>`，不是常规的 `<button>` 元素
- ❗ 它的内部方法 `_onPublish` 是发布函数，`_onSave` 是保存函数
- ❗ 必须先「一键排版」→「下一步」后，发布按钮组件才会渲染
- ❗ 第一次尝试时从笔记管理页面手动发布成功（用户操作），第二次通过调用 `_onPublish` 自动发布成功
- ✅ 文章发布后出现在笔记管理的「审核中」标签
- ✅ 登录态保存于 `xiaohongshu_auth.json`
