### Playwright 技术要点

1. **`page.evaluate()` 传参限制**：只接受1个参数，多个参数需包装为对象：
   ```js
   // ❌ 错误 - Too many arguments
   await p.evaluate((a, b) => ..., a, b);
   // ✅ 正确
   await p.evaluate(({a, b}) => ..., {a, b});
   ```

2. **点击不响应 dispatchEvent**：Vue 事件委托在父元素，`dispatchEvent` 不触发。
   - ✅ `page.locator().click({force:true})` 可能超时等待交互性检查
   - ✅ `page.evaluate(el => el.click())` 直接用 JS 点击可行

3. **API 拦截获取课程数据**：`page.on('response', handler)` 可捕获 API 返回体，通过 `resp.json()` 解析。
